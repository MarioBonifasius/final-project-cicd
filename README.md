# Final Project CI/CD Pipeline

## Nama Proyek: Final Project CI/CD Pipeline - Mario Bonifasius

## Deskripsi
Proyek ini adalah implementasi CI/CD pipeline menggunakan GitHub Actions dan Tekton Pipeline.

## Pipeline Steps
1. Cleanup
2. Git Clone
3. Linting (flake8)
4. Testing (nose)
5. Build (buildah)
6. Deploy (OpenShift)

## Teknologi
- Python 3.9
- Flask
- GitHub Actions
- Tekton Pipeline
- OpenShift
